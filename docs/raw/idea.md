# Realtime Chat

Planeje a implementação de um chat em tempo real.

## Stack

- Frontend: React + Vite + Tailwind + Testes
- Backend: Go + Testes
- Docker

## Frontend

Use a skill `frontend-design`.
Implementação simples.
Um chat comum (visualização das mensagens + input pra enviar e botão de envio).
À direita a lista de pessoas naquele chat.
As mensagens exibem o nome / id do usuário, além da hora.

## Plano

Separe o plano em etapas bem definidas, desenvolvendo cada ponto separadamente.
Pode-se criar uma spec pra cada frente: primeiro infra (docker), depois backend (go) e por último frontend (react).
É importante a existência de testes no backend. Como o frontend é simples, inicialmente não vamos criar testes.
